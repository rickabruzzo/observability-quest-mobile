# Intro Cutscene — Implementation Plan (v2 sub-project 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** After the character sheet, play Rick's intro — eight EGA stills cut together with almost no animation, then the VGA bedroom where the player's hero gets out of bed, changes and walks out — skippable, and working today on placeholder plates that the generated art replaces without code changes.

**Architecture:** A build tool (`tools/build_intro.py`) turns the plates and their single-change edits into 320×200 PNGs plus precomputed "other light state" variants and a JSON manifest, so the browser never touches pixels: the intro screen only blits whole images and draws LCD text with a built-in 5×7 font. Shot order, durations and the two-state flashes are a pure timeline table (`js/intro/timeline.js`). The hero gains a pyjama outfit and a sit-up pose in the Python reference and the JS port, proven by fixtures as before.

**Tech Stack:** ES modules, `node --test`, Playwright e2e, Python 3 + Pillow + NumPy, pytest.

**Spec:** `docs/superpowers/specs/2026-11-10-sci-adventure-design.md` — *Intro and coda*; `docs/intro-storyboard.md`; art brief `briefs/intro-shots-brief.md`.

## Global Constraints

- Order: TITLE → CREATOR → **INTRO** → PREVIEW (PREVIEW stands in for the chapter deal until the room engine exists).
- Shots 1–8: **no tweened motion, no fades.** Only cuts, two-state swaps (whole-image), flashing text, scrolling text. Blink/flash rate ≤ **2 Hz**.
- Shot table (ms): 1 dark blink 3000 · 2 pager "Help!" 2500 · 3 face asleep → eye crack (cut at 1800) 3000 · 4 arm 1500 · 5 face awake, green flash 2000 · 6 pager marquee 5000 · 7 misery 2000 · 8 lamp (warm swap at 700) 1500 · 9 bedroom, hero sequence ≈ 8000.
- LCD copy, exactly: `Help!` and `Backend is down. Website is down. Database is down. Get in here! -CTO`. Wall title, exactly: `OBSERVABILITY QUEST I` (GloryQuest) and `So you want to be on-call?` (VT323).
- Plates are 320×200 logical; sources arrive as 640×400 PNGs in `scratch/intro_gen/` named per the brief (`A_room_dark`, `B_nightstand`, `B_arm`, `B_lamp`, `C_face_asleep`, `C_eye_crack`, `C_awake`, `C_misery`, `D_bedroom_vga`). Missing sources → labelled placeholders; the game must run either way.
- An edit must equal its plate outside the changed region: the tool fails (non-zero exit, names the file) when more than **35%** of pixels differ.
- Intro assets total ≤ **400 KB**; they load after the title is interactive (on entering the sheet), never before.
- Tap advances one shot; **Skip** (short label "Skip") in the right column ends the intro. Reduced motion: no blink, no flash, no marquee (message shown whole, wrapped), hero teleports.
- Hero: `outfit: 'hoodie' | 'pj'` is a render argument, **not** a creator option and not stored in `oq.hero`. Pose `situp` added. Fixtures regenerate; JS must match byte for byte.
- Sound is optional and silent-safe: a pager beep on blink-on, a click at the lamp swap, nothing if audio is unavailable or muted. No theme yet.
- Commits authored `Claude <noreply@anthropic.com>` with the attribution trailer; never push.

### Task 2: Intro asset build

**Files:** Create `tools/build_intro.py`, `tools/tests/test_build_intro.py`; outputs `assets/intro/*.png`, `assets/intro/intro.json`.

**Interfaces:**
- CLI: `python3 tools/build_intro.py [--src scratch/intro_gen] [--out assets/intro] [--placeholders]`. For each expected source: if present, downsample 640×400 → 320×200 nearest, reduce to ≤ 32 colours (adaptive, no dither — the art is already dithered); if absent (or `--placeholders`), draw a labelled flat placeholder (dark fill, shot name in block letters, a green rectangle where the LCD goes on B plates, an empty light wall band on D).
- Edits (`B_arm`, `B_lamp`, `C_eye_crack`, `C_awake`, `C_misery`) are compared with their plate (`C_misery` against `C_awake`): pixels within tolerance 24/channel are snapped to the plate's pixel; if > 35% differ → exit 1 with the file name.
- Derived states (whole images, no runtime pixel work): `A_room_dark` → none (the other state is black, drawn by the game); `C_awake_lit` = `C_awake` with green channel ×1.35 and others ×0.9 clamped, re-quantised; `B_lamp_lit` = `B_lamp` with a warm lift (R×1.5+40, G×1.35+30, B×1.0+5, clamped).
- `intro.json`: `{ "size": [320,200], "images": { name: "file.png", … }, "lcd": { "x","y","w","h" }, "wall": { "x","y","w","h" }, "bed": { "x","y" }, "door": { "x" }, "floorY": n, "placeholder": true|false }`. `lcd` = bounding box of the largest connected bright-green region in `B_nightstand` (G > 150, G > R+40, G > B+40), inset by 2 px; `wall` = fixed `{x: 24, y: 14, w: 232, h: 44}` unless `scratch/intro_gen/intro.overrides.json` supplies values; likewise `bed {x: 60, y: 96}`, `door {x: 286}`, `floorY: 176`.
- Functions for tests: `downsample(img) -> Image`, `snap_to_plate(edit, plate, tol=24) -> (Image, changed_fraction)`, `find_lcd(img) -> (x,y,w,h)`, `placeholder(name) -> Image`, `build(src, out, placeholders=False) -> manifest dict`.

### Task 3: 5×7 LCD font and pager text maths

**Files:** Create `js/intro/font5x7.js`, `js/intro/pager.js`, `tests/intro-text.test.js`.

**Interfaces:**
- `font5x7.js`: `GLYPHS` (ASCII 32–126, 7 rows × 5-bit ints), `textWidth(text, scale = 1) → px` (6·scale per char, minus the trailing gap), `drawText(ctx, text, x, y, scale, color)` — fillRect per lit pixel; unknown characters draw a hollow 5×7 box.
- `pager.js`: `lcdScale(lcd) → integer ≥ 1` (largest scale whose 7-px glyph height fits `lcd.h − 4`); `flashOn(elapsedMs, periodMs = 500) → boolean` (on for the first half of each period); `marqueeX(text, lcd, scale, elapsedMs, durationMs) → x` — starts with the text's left edge at the LCD's right edge and ends with its right edge at the LCD's left edge, linear, rounded to whole `scale` px; if the text fits (`textWidth ≤ lcd.w − 4`) returns the centred x for every t; `drawLcd(ctx, lcd, text, x, scale, color = '#0F200F')` clips to the LCD rect.
